# Web Development Internship – Task 2

This repository contains **Task 2** of my Web Development Internship. The task focuses on designing and developing a landing page for a travel agency.

## Project Overview

The project is a modern and visually appealing **travel agency landing page** designed to showcase travel services and destinations. It focuses on creating an attractive user interface using HTML and CSS.

## Contents

- **index.html** – Main HTML file containing the structure and content of the landing page.
- **style.css** – CSS stylesheet used to design and style the landing page.
- **Travel Hero Logo** – Logo used for the travel agency branding.

## Features

- Attractive travel agency landing page
- Travel-themed design
- Custom branding and logo
- User-friendly layout
- Styled using CSS
- Clean and simple webpage structure

## Technologies Used

- HTML
- CSS

## Purpose

This project was created as part of my Web Development Internship to practice designing and developing responsive and visually appealing landing pages using HTML and CSS.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the travel agency landing page.
